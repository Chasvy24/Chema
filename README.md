# Chema

Application personnelle (PWA) : budgets CHF et MAD, échéances, documents et épargne.
Les données restent uniquement sur le téléphone — ce dépôt ne contient que le code de l'application.

- Branche `main` : application compilée, publiée par GitHub Pages.
- Branche `source` : code source, tests et documentation complète (README).
